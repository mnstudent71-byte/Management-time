# مدیریت زمان – Time Manager (Android alarm app)

Persian alarm app: Persian clock and date, alarm at a chosen Persian date and time (or daily),
turns the screen on over the lock screen, vibrates and plays sound until you press the off button,
and lets you choose a system ringtone, an audio file from the phone, or type a file path.

## Build the APK with GitHub
1. Upload all files of this project to a new GitHub repository (keep the folder structure,
   including `.github/workflows/build.yml`).
2. Open the **Actions** tab → **Build Android APK** → **Run workflow** (it also runs on every push).
3. When it finishes, open the run and download **TimeManager-APK** (contains `app-debug.apk`).
4. Install the APK on your phone (allow "install unknown apps" if asked).

Requires Android 8.0 or newer.
